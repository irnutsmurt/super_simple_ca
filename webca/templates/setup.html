Want a hand setting this up?

This walkthrough gets you to a secure setup in a few steps: create a passphrase-protected root, put an intermediate underneath it to do the day-to-day signing, take the root offline, and (optionally) issue SuperSimpleCA its own HTTPS certificate. You can stop and do the rest by hand at any point.

{# ------------------------------------------------------------------ step 1: root #} {% elif step == "root" %}

Step 1 — Create the root CA

This is your trust anchor. The walkthrough protects it with a passphrase so you can take it offline later. Clients will trust this root; certificates chain up to it.

Root passphrase (required)
You'll need this once more to create the intermediate. Store it somewhere safe.
{# ------------------------------------------------------------------ step 2: intermediate #} {% elif step == "intermediate" %}

Step 2 — Create the intermediate

The root signs one intermediate; from here on the intermediate signs every certificate, so the root can go offline. Enter your root passphrase to authorize this.
